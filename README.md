# 🎲 DiceX - A Smart Dice Roller  

**DiceX** is a simple yet fun dice rolling app built with **Jetpack Compose** in Kotlin. Tap anywhere to roll two virtual dice and see their total, with a short message based on the score.

## Technologies Used  
- **Kotlin**  
- **Jetpack Compose**  
- **State Management**  
- **Random Number Generation**  

## Features  
✅ **Tap to Roll** – Generates two random values from 1 to 6.<br>
✅ **Score Feedback** – Displays the total and a message for the current roll.<br>
✅ **Dynamic UI** – Displays corresponding dice faces for each roll.  

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/codewithmahad/DiceX-App.git
   ```
2. Open the repository root in Android Studio and let Gradle sync using the included wrapper.
3. Install the SDK components requested by Android Studio, then run the app on an emulator or a connected Android device.
